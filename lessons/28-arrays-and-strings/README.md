# Lesson 28: Arrays and Strings: The Foundation of Every Interview

*Part D: Data Structures and Algorithms*

## Summary
- How an array (Python list) sits in memory.
- Traversal, in-place updates, and the cost of insert and delete.
- Common moves: reverse, rotate, merge, remove duplicates.
- String versions of the same ideas.

## Complexity
Remove duplicates: O(n) time, O(1) space. Rotate: O(n) time, O(1) space.

## Coding questions
- Q1 (Easy): Move zeros to the end
- Q2 (Easy): Merge two sorted arrays
- Q3 (Medium): Product of array except self
- Q4 (Hard): Maximum subarray sum (Kadane)

## Recap
- Arrays are fast to read, slow to shift.
- Write-pointer and reversal tricks keep space at O(1).
