# Lesson 13: Object-Oriented Python: Classes, Objects and Dunder Methods

*Part B: Advanced Python*

## Summary
- Classes, objects, attributes and methods.
- `__init__` and `self`.
- Dunder (double underscore) methods: `__repr__`, `__eq__`, `__len__`, `__lt__`, `__getitem__`.
- Class vs instance attributes.

## Complexity
Creating an object is O(1) plus whatever `__init__` does. Method calls are O(1) plus their body.

## Coding questions
- Q1 (Easy): Point class with string form
- Q2 (Easy): Counter class
- Q3 (Medium): Vector with `+` and `==`
- Q4 (Hard): A list-like class with indexing and iteration

## Recap
- Classes bundle data and behaviour.
- Dunder methods plug your class into Python syntax.
- We will use classes for stacks, nodes and trees.
- Next: inheritance.
