# Lesson 3: Operators and Expressions (Arithmetic, Comparison, Logic, Bitwise)

## Summary
- Arithmetic operators, including `//`, `%` and `**`.
- Comparison and chained comparison.
- Logical operators and short-circuit behaviour.

## Complexity
Each operator on small numbers is O(1). On huge ints, cost grows with digit count.
