# Lesson 66: Intervals: Merge, Insert and Schedule

*Part D: Data Structures and Algorithms*

## Summary
- Overlap test for two intervals.
- Merge overlapping intervals.
- Insert an interval into a sorted list.
- Meeting rooms with a heap or a sweep line.

## Complexity
Sorting O(n log n), merging O(n), space O(n).

## Coding questions
- Q1 (Easy): Can a person attend all meetings?
- Q2 (Easy): Do two intervals overlap?
- Q3 (Medium): Insert interval
- Q4 (Hard): Minimum meeting rooms

## Recap
- Sort by start, then sweep.
- Heap or sweep line for counting simultaneous meetings.
- Next: bit manipulation.
