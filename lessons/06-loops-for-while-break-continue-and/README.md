# Lesson 6: Loops: for, while, break, continue and range

*Part A: Python Foundations*

## Summary
- `for` loops over sequences and `range`.
- `while` loops and when to stop them.
- `break`, `continue` and `else` on loops.
- `enumerate`, `zip` and nested loops.

## Complexity
- One loop over n items: O(n). Two nested loops over n: O(n²). `while` depends on how fast it reaches the end.

## Coding questions
- Q1 (Easy): Sum 1 to n
- Q2 (Easy): Multiplication table
- Q3 (Medium): Is a number prime?
- Q4 (Hard): Print a pyramid

## Recap
- for walks items; while waits for a condition.
- break, continue and else control flow.
- Loops are the source of complexity.
