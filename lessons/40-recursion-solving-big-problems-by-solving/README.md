# Lesson 40: Recursion: Solving Big Problems by Solving Smaller Ones

*Part D: Data Structures and Algorithms*

## Summary
- Base case and recursive case.
- How the call stack works.
- Recursion vs loops, and recursion depth.
- Classic problems: factorial, power, Fibonacci, Tower of Hanoi.

## Complexity
Factorial: O(n) time, O(n) stack space. Fast power: O(log n) time and space. Naive recursive Fibonacci: O(2ⁿ).

## Coding questions
- Q1 (Easy): Sum of digits
- Q2 (Easy): Reverse a string recursively
- Q3 (Medium): Fibonacci with and without memo
- Q4 (Hard): Tower of Hanoi

## Recap
- Base case + smaller problem.
- The call stack costs space.
- Memoize to avoid repeats.
- Next: backtracking.
