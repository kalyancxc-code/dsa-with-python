# Lesson 7: Functions: Parameters, Return Values and Scope

*Part A: Python Foundations*

## Summary
- Defining and calling functions, with parameters and return values.
- Default, keyword and positional arguments.
- Scope: local and global names.
- The dangerous mutable default argument.
- Docstrings and small, testable functions.

## Complexity
A call has a small fixed cost, O(1). Each call uses stack space for its locals, which matters for recursion later.

## Coding questions
- Q1 (Easy): Square of a number
- Q2 (Easy): Average of a list
- Q3 (Medium): Factorial
- Q4 (Hard): Fibonacci, the n-th number, in O(n)

## Recap
- Functions take input and return output.
- Names inside are local.
- Use None for mutable defaults.
- Next: lists, tuples, sets and dicts.
