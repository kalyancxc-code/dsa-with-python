# Lesson 48: Binary Search Variants: Bounds and Search on the Answer

*Part D: Data Structures and Algorithms*

## Summary
- First and last occurrence (lower and upper bound).
- Peak element.
- Search on the answer using a "can we do it?" check.
- A reusable template.

## Complexity
Each is O(log n) time, O(1) space.

## Coding questions
- Q1 (Easy): Count occurrences in a sorted list
- Q2 (Easy): First bad version
- Q3 (Medium): Find a peak element
- Q4 (Hard): Koko eating bananas (minimum speed)

## Recap
- Bounds find the first/last position.
- Any yes/no flip can be searched in O(log).
