# Lesson 55: Depth-First Search (DFS): Islands, Cycles and Paths

*Part D: Data Structures and Algorithms*

## Summary
- Recursive and iterative DFS.
- Counting islands on a grid (flood fill).
- Cycle detection in directed and undirected graphs.
- All paths and clone-like traversals.

## Complexity
O(V + E) time. Space O(V) for visited and recursion (grid: O(R·C) worst case).

## Coding questions
- Q1 (Easy): Flood fill
- Q2 (Easy): All paths from source to target in a DAG
- Q3 (Medium): Detect a cycle in a directed graph
- Q4 (Hard): Maximum area of an island

## Recap
- DFS goes deep, then backtracks.
- Islands, cycles and paths are the classics.
- Next: topological sort.
