# Lesson 10: Comprehensions: Short, Readable Loops

*Part A: Python Foundations*

## Summary
- List, set and dict comprehensions.
- Filtering with `if` and choosing with `if/else`.
- Nested comprehensions.
- Generator expressions.

## Complexity
Same as the loop it replaces: O(n) for one `for`, O(n·m) for two. A list comprehension uses O(n) memory; a generator uses O(1).

## Coding questions
- Q1 (Easy): Squares of even numbers
- Q2 (Easy): Lengths of words
- Q3 (Medium): Flatten and transpose
- Q4 (Hard): Invert a dict, grouping duplicates

## Recap
- Comprehensions map and filter in one line.
- Use generators for large data.
- Readability first.
- Next: files and exceptions.
