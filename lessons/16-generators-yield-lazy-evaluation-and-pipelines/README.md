# Lesson 16: Generators: yield, Lazy Evaluation and Pipelines

*Part B: Advanced Python*

## Summary
- Generator functions with `yield`.
- Generator expressions.
- Lazy evaluation and memory savings.
- `yield from` and pipelines.

## Complexity
Time is the same as a loop, O(n). Memory is O(1) for the generator itself.

## Coding questions
- Q1 (Easy): Even numbers generator
- Q2 (Easy): Generator expression sum
- Q3 (Medium): Chunk a list
- Q4 (Hard): Permutations generator

## Recap
- `yield` pauses and resumes.
- Generators are lazy and memory-light.
- Pipelines chain generators.
