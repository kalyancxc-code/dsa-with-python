# Lesson 37: Stacks: Last In, First Out

*Part D: Data Structures and Algorithms*

## Summary
- What a stack is and its operations.
- Implementing a stack with a list.
- Classic uses: matching brackets, undo, evaluating expressions.
- A stack with O(1) minimum.

## Complexity
Each character is pushed and popped at most once: O(n) time, O(n) space.

## Coding questions
- Q1 (Easy): Reverse a string using a stack
- Q2 (Easy): Min stack with O(1) minimum
- Q3 (Medium): Evaluate reverse Polish notation
- Q4 (Hard): Decode a string like 3[a2[c]]

## Recap
- Stack = LIFO with O(1) push/pop.
- Great for matching and undo.
- Next: queues and deques.
