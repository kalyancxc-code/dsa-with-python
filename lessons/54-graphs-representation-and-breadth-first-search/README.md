# Lesson 54: Graphs: Representation and Breadth-First Search (BFS)

*Part D: Data Structures and Algorithms*

## Summary
- Graph vocabulary: node (vertex), edge, directed, weighted.
- Adjacency list vs adjacency matrix.
- BFS with a queue and the visited set.
- Shortest path in an unweighted graph; grids; connected components.

## Complexity
Time O(V + E), space O(V) for the queue and visited set.

## Coding questions
- Q1 (Easy): Is there a path?
- Q2 (Easy): Number of connected components
- Q3 (Medium): Shortest path in a grid maze
- Q4 (Hard): Word ladder

## Recap
- Graph = nodes + edges; use adjacency lists.
- BFS = queue + visited; shortest path by edges.
