# Lesson 50: Tree Traversals: Inorder, Preorder, Postorder and Level Order

*Part D: Data Structures and Algorithms*

## Summary
- DFS orders: preorder, inorder, postorder (recursive and iterative).
- BFS: level order with a queue.
- Which traversal to use for which task.
- Right-side view and zigzag.

## Complexity
All traversals: O(n) time. DFS space O(h). BFS space O(w), where w is the maximum width.

## Coding questions
- Q1 (Easy): Sum of all nodes (any traversal)
- Q2 (Easy): Leaf values left to right
- Q3 (Medium): Right side view
- Q4 (Hard): Zigzag level order

## Recap
- Preorder, inorder, postorder = DFS; level order = BFS.
- Pick the order that matches the task.
- Next: binary search trees.
