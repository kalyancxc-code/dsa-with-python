# Lesson 51: Binary Search Trees (BST): Ordered Data with Fast Search

*Part D: Data Structures and Algorithms*

## Summary
- The BST rule and why search is fast.
- Insert, search, min/max and delete.
- Validating a BST.
- Balanced vs skewed trees.

## Complexity
Balanced: search, insert, delete O(log n). Skewed: O(n). Space O(n).

## Coding questions
- Q1 (Easy): Search in a BST (recursive)
- Q2 (Easy): Minimum and maximum
- Q3 (Medium): Validate a BST
- Q4 (Hard): K-th smallest element

## Recap
- Ordered tree: left smaller, right larger.
- O(log n) when balanced.
- Validate with ranges.
